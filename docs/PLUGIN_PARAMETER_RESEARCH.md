# Plugin parameter research: Unsharp Mask, Sharpen, Haze Flare (bloom)

For the plugin-based look-fit system. Every item is tagged: **[SOURCE]** read in a published page, **[EMPIRICAL]** reported by users comparing outputs, **[UNKNOWN]** not published, so it must be fitted and labelled as fitted in the spec. Nothing here is guessed silently.

## 1. Unsharp Mask (After Effects)

**Formula [SOURCE, Wikipedia "Unsharp masking"]:** `sharpened = original + (original - blurred) * amount`. Amount scales the strength of the overshoot (edge contrast) and does not change the width of the edge rims. Radius sets the width of the edge rims (small radius = fine detail). Threshold sets the minimum brightness change that gets sharpened, to keep smooth areas from becoming speckled. A larger radius gives faint halos; sharpening also amplifies noise.

**After Effects definitions [SOURCE, Adobe help, Blur & Sharpen effects]:**
- Radius: "the distance from the edge within which pixels are adjusted for contrast."
- Threshold: "the largest difference between adjacent pixels that still gets no contrast adjustment. A lower value produces a stronger result. Too low and it adjusts contrast across the whole image, which can add noise." This is a **gate**: differences at or below the threshold are left alone.
- Supports 8/16/32 bpc. (The Adobe page does not list Amount; the real effect has an Amount control.)

**Radius to Gaussian sigma [EMPIRICAL, ImageMagick forum]:** a Photoshop Gaussian radius of 3 matched ImageMagick sigma 3 within one grey level, and Photoshop USM at amount 50, radius 3, threshold 0 was matched with sigma 3. So **start with sigma = radius in pixels** (not radius/2). This is Photoshop evidence; After Effects' exact mapping is **[UNKNOWN]**, so the fit must still test sigma = radius against 0.5 x radius and 2 x radius and keep the best.

**Plugin parameters and search ranges:**
| parameter | meaning | search range |
|---|---|---|
| amount | percent of the difference added back | 0 to 500 % (AE default is a small number such as 50) |
| radius | Gaussian sigma in pixels, stored as a fraction of frame height | 0.3 px to 3 % of height |
| threshold | gate in 0-255 units: no change when abs(diff) <= threshold | 0 to 40; test hard gate and soft coring (`sign(d)*max(abs(d)-t,0)`) |
| channels | RGB per-channel vs luma only | test both; pick by held-out edge error |
| colour space | gamma-encoded vs linear light | test both (AE works in gamma unless "linear blending" is on) |

**Fit procedure:** on the colour-corrected base, measure edge profiles across line art: halo height and width on both sides, compare with the target; fit a nuisance pre-blur for the target's recompression softness and keep it out of the look. Use the threshold to avoid boosting compression blocks (a visible failure in the user's crops: speckle and halos on skin). A two-stage model (tight radius, small amount + wide radius, small amount) is allowed if one stage cannot explain the profile. Report the fitted values against the user's own AE-style hand settings (Unsharp radius 22.1 / amount 32 in a 1080p project) and say how far apart they are.

**Correction to an earlier build:** the first Floby's CC shader used sigma = radius / 2 for the wide unsharp. The evidence above points to sigma = radius, so that radius was probably half too small. Re-fit it.

## 2. Sharpen (After Effects)

- **[SOURCE]** Adobe: "The Sharpen effect increases the contrast where color changes occur." It has a single strength control, is not affected by the layer's quality setting (so it is a fixed small neighbourhood) and is GPU accelerated.
- **[UNKNOWN]** The kernel and the mapping from the Amount value to strength are not published anywhere I could find. The Sapphire/other pages found were not about this effect.
- **Plugin model (fitted, say so in the spec):** `out = x + k(amount) * (x - Blur_small(x))`, where `Blur_small` is one of: 4-neighbour average, 8-neighbour average, 3x3 binomial [1 2 1]/4 outer product. Fit which kernel and the factor from edge profiles; test whether `k` is linear in amount.
- **Exact calibration (optional, best accuracy):** Keyflaw's own built-in Sharpen follows After Effects. Export a synthetic step edge and a 1-pixel line (generated by the AI) through the built-in Sharpen at amounts such as 10, 34, 50, 100 and measure the kernel directly. This turns the unknown into a measurement.
- Search: amount 0 to 100 (project value 34), `k` 0 to 3.
- Keep it separate from Unsharp Mask: two plugins, each with its own parameters.

## 3. Haze flare (bloom/glow)

There is no single published algorithm. The common structure across commercial glows is the same, so the plugin should expose these parameters and fit them:

- **[SOURCE, Boris FX Sapphire Glow]** Glows are generated from areas **brighter than a threshold** (default 0.5; at 0 everything non-black glows). Brightness scales all glows (default 2). Glow width scales distance (default 0.4), with separate X and Y widths (streaks). **Separate Red / Green / Blue widths (defaults 1, 1.2, 1.4)** make the glow shift colour with distance. A tint colour applies to the glow. Default combine mode is **Screen** (Add, Mult, Overlay, Difference also offered). Option "Light Background" makes the glow light the background.
- **[SOURCE, Maxon Glow]** Threshold with a softness (feather), size with separate width and height, a falloff curve, intensity that raises brightness while reducing opacity, gamma, and two colours (inner and outer).

**Plugin model (real bloom, not an overlay):**
1. Source = the colour- and sharpness-corrected picture.
2. `bright = max(luma-or-channel - threshold, 0)` with a soft knee. The glow comes from the picture's own bright areas.
3. Blur `bright` at 3 to 5 scales with sigmas as fractions of frame height (for example 0.5 %, 1 %, 2 %, 4 %, 8 %), per-scale weights, and per-channel width multipliers (R:G:B near 1 : 1.2 : 1.4 is the Sapphire default; fit it).
4. Tint colour, intensity, then **Screen** with the base (test Add and Soft Light too).
5. Optional anisotropy (X/Y widths, rotation) and an optional positional envelope (a soft mask favouring one side of the frame) **only if the fit proves it helps**, and the colour must still come from the picture.
6. Required real-bloom test: the effect must be zero on a black frame and strongest around bright shapes. A fixed-colour blob that ignores the picture is an overlay and is rejected.
7. Existence test first: if the smooth low-frequency residual is within error after colour and sharpening, record `haze flare: absent`.

| parameter | search range |
|---|---|
| threshold | 0.3 to 0.95 (+ softness 0 to 0.3) |
| scales (sigma / height) | 0.003 to 0.15, 3 to 5 scales |
| per-scale weights | 0 to 1 |
| channel width multipliers | 0.7 to 2.0 |
| tint RGB | 0 to 1 |
| intensity | 0 to 2 |
| blend | Screen (default), Add, Soft Light |

## 4. Limits of this research
- AE's exact Sharpen kernel and its Radius-to-sigma mapping are not documented; the plan above labels them as fitted.
- The Maxon and Sapphire pages describe controls, not algorithms; the multi-scale blur structure is the common practice, not a quoted formula.
- All of this must be validated on real frame pairs with held-out error, and the spec must say which parameters are measured and which are assumed.
